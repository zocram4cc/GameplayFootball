### 1. PES's cutscene director — decode `table_*.bin` and drive the goal from it (P1)
Owner: "our celebrations and camera stuff looks nothing like the source game despite being imported. We're clearly missing something."

**Finding.** Each `.fdc` is one *state* of a scene: cameras + actor spawn/yaw/gani + props. What assembles a goal — which run-celebration, which celebration, whether teammates hug (LV2/LV3 by count), whether it goes to the fence / behind the goal / flag / camera, how it finishes — is `dt12_fixdemo_all/common/demo/fixdemo/goal/table_goal.bin` (884 KB), and `table_{ent,foul,change,end,timeup,pk,result,mode}.bin` beside it. A state machine we never read. We play ONE `GOAL_CELEBRATE_NNNN` under a six-beat camera template authored from a video; PES plays
`GOAL_START -> GOAL_RUN_30_*/GOAL_RUN_40_* -> GOAL_CELEBRATE_NNNN (421) -> GOAL_HUGA/HUGB_LV2/LV3 -> GOAL_A_{BEHINDGOAL01-03,OVERBOARD,FLAG_DANCE/GOLF/SNIPER,CAMERAAPPEAL,CONFETTI,SUBSTITUTEHUG,TURNBYAREAF} -> GOAL_C_FINISH_{SUCCESS,FAILURE,STAND_*} -> GOAL_END_`, side branches `GOAL_S_OWNGOAL_{WANDERING,CROUCHING,GK}`, `GOAL_S_OFFSIDE*`, `GOAL_S_GOLAZO*`, `GOAL_S_ASSISTTHANX`.

**Format so far (PES21).** Header 16 u32: `/*` magic; `[3]`=0x349f; `[15]`=19 (name stride); `[8]`=0x3c = start of a 159-entry u32 name-offset index. Sections at 0x1ac9, 0x2a2f, 0x349f, 0xe2c0, 0x100b9, 0x25d10, 0x38b3c (f32, 1000-1600), 0x433f8 (7,3 alternating), **0x50674 = CSR adjacency (`count<<16 | first`)**, **0x659bd = 5-u32 edge records `0x??0a0203, 1, 0, 0, 0x000f0100`**, 0x707e6, 0x722af = 721 state names (396 distinct).
