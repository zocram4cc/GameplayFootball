### Why our goal presentation looks nothing like PES — the director table is unread (P1, next session)
Owner: "our celebrations and camera stuff looks nothing like the source game despite being imported. We're clearly missing something." Found it:
`dt12_fixdemo_all/common/demo/fixdemo/goal/table_goal.bin` (884 KB) - and `table_{ent,foul,change,end,timeup,pk,result,mode}.bin` beside it - are PES's **cutscene director**: a state machine that assembles a goal from many `.fdc`s. We import the `.fdc`s one by one and then play ONE `GOAL_CELEBRATE_NNNN` clip under a six-beat camera template I authored from a video. PES plays:
`GOAL_START -> GOAL_RUN_30_*/GOAL_RUN_40_* (a run-celebration picked by distance) -> GOAL_CELEBRATE_NNNN (421) -> GOAL_HUGA/HUGB_LV2/LV3 (teammates arrive, by count) -> GOAL_A_{BEHINDGOAL01-03,OVERBOARD,FLAG_DANCE/GOLF/SNIPER,CAMERAAPPEAL,CONFETTI,SUBSTITUTEHUG,TURNBYAREAF} -> GOAL_C_FINISH_{SUCCESS,FAILURE,STAND_*} -> GOAL_END_`, with side branches `GOAL_S_OWNGOAL_{WANDERING,CROUCHING,GK}`, `GOAL_S_OFFSIDE*`, `GOAL_S_GOLAZO*`, `GOAL_S_ASSISTTHANX`. Each state = its own `.fdc` (cameras + actor spawn/yaw/gani + props).
Format so far (PES21): header 16 u32 (`/*` magic; `[3]`=0x349f name-block length; `[15]`=19 name stride; `[8]`=0x3c start of a 159-entry u32 name-offset index); sections at 0x1ac9, 0x2a2f, 0x349f, 0xe2c0, 0x100b9, 0x25d10, 0x38b3c (f32 block, values ~1000-1600), 0x433f8 (alternating 7,3), **0x50674 = CSR adjacency (`count<<16 | first`: 3@0, 3@3, 3@6, 2@9 ...)**, **0x659bd = 5-u32 edge records `0x??0a0203, 1, 0, 0, 0x000f0100` (weights/conditions)**, 0x707e6, 0x722af = 721 state names (396 distinct). Decode the adjacency + edges first; that IS the sequencer.
Older generations: PES16-19 installs at `path/to/PES1{6,7,8,9}` are still `.cpk`-packed; extract `dt12`/fixdemo to compare tables (format may be simpler in PES16). PES15 bottle has a different anim system.
Then: `goal_cutscenes.py` -> emit the graph; `Match::StartGoalCast` walks it instead of the `GoalSequence` beat table; camera cuts come from each state's `.fdc` cut table (`CameraCut.start_frame`, `blend`), not from my template.
Also: the released showdown only imported ~a third of the goal `.fdc`s (534 chors / 731 camtracks of 1691 files, 1635 bases).
